features:
  - title: Events, not items
    details: An event is an authored object with its own title, date, description and tags. Your collections and exports stay bibliographic.
  - title: Typed source links
    details: Each link to a library item carries a named type from a vocabulary you control, so "supports" and "contradicts" stay distinguishable.
  - title: Several timelines, one axis
    details: Timelines are separate documents, drawn together on one chronological axis to compare what preceded what.
  - title: Rides Zotero sync
    details: Data lives in note items, a native field, so it syncs with everything else. No WebDAV and no file-sync setup.
